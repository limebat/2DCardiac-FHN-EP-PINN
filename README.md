# 2DCardiac-FHN-EP-PINN
FHN EP-PINN model for cardiac ion modeling, using simulated detailed data, ref. Mitchell-Schaeffer from 2003 Bulletin of Mathematical Biology

To run main code, run the py file. Run the .m file to generate dataand edit simulated data. TimeVH.txt is the time and V-H data of the detailed Mitchell-Shaeffer model.
